PKD - PlatinumSrc Key-value Database

- .pkd file extension
- Current version is 0.0
- All data should be little endian

Format:

    <Header> <Data>

    Header:

        <char[3]: {'P', 'K', 'D'}>
        <u8: Major version>
        <u32: Offset of root <Key> <Block>>
        <u32: Offset of <Free space tracker> <Block> (0 if none yet)>

    Data:

        { <Block> | <Block continuation> | <Data segment> | <Free space> }...

        Block:
            <u32: Total size of data>
            <u32: Size of <Data segment>>
            <u32: Used bytes in <Data segment>>
            <u32: Offset of <Data segment>>
            <u32: Offset of first <Block continuation>>
        Block continuation:
            <u32: Size of <Data segment>>
            <u32: Used bytes in <Data segment>>
            <u32: Offset of <Data segment>>
            <u32: Offset of next <Block continuation>>

        Data segment:
            <u8[]: Part or whole of <Key>, <Value>, or <Free space tracker>>

        Free space:
            <u8[]: Unused>

        Free space tracker:
            <u32: Total slots>
            <u32: Index of first unused entry (-1U for none)>
            [ { <Free space tracker entry> | <Unused free space tracker entry> } ]...
        Free space tracker entry:
            <u32: Offset of <Free space>>
            <u32: Size>
        Unused free space tracker entry:
            <u32: 0>
            <u32: Index of next unused entry (-1U for none)>

        Key:
            <u32: Offset of <Value> <Block> (0 if PKD_TYPE_NONE)>
            <u32: Sub-key count>
            <u32: Index of first unused entry (-1U for none)>
            [ { <Sub-key> | <Unused sub-key> } ]...
        Sub-key:
            <u32: Offset of Sub-<Key> <Block>>
            <u32: Offset of name <String> <Block>>
            <u32: Name CRC32>
        Unused sub-key:
            <u32: 0>
            <u32: Index of next unused entry (-1U for none)>
            <u32: Index of previous unused entry (-1U for none)>

        Value:
            <u8:
                <3 bits: 0>
                <1 bit: Is array>
                <4 bits:
                    { PKD_TYPE_BOOL
                    | PKD_TYPE_I8
                    | PKD_TYPE_I16
                    | PKD_TYPE_I32
                    | PKD_TYPE_I64
                    | PKD_TYPE_U8
                    | PKD_TYPE_U16
                    | PKD_TYPE_U32
                    | PKD_TYPE_U64
                    | PKD_TYPE_F32
                    | PKD_TYPE_F64
                    | PKD_TYPE_STR }
                >
            >
            [u32: Array size]
            { <u8: Bool>
            | <i8>
            | <i16>
            | <i32>
            | <i64>
            | <u8>
            | <u16>
            | <u32>
            | <u64>
            | <float>
            | <double>
            | <u32: Position of <String> <Block>>
            | [u8: Bool bitmap]...
            | [i8]...
            | [i16]...
            | [i32]...
            | [i64]...
            | [u8]...
            | [u16]...
            | [u32]...
            | [u64]...
            | [float]...
            | [double]...
            | [u32: Position of <String> <Block>]... }

        String:
            <char[]: Data>
