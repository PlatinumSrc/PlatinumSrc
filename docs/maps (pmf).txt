PMF - PlatinumSrc Map File/Format

- .pmf file extension
- Current version is 0.0
- All data is little endian
- Compression is LZ4F

Format:

    <Header> <Data>

    Header:

        <char[3]: {'P', 'M', 'F'}>
        <u8: Major version>

    Data:

        <u32: Offset of <Info>>
        <u32: Offset of <Extension table>>
        <u32: Offset of <Level table>>
        <Info>
        <Level table>
        <Extension table>

        Info:
            <u16: String table length>
            <u8: Gamemode count minus 1 (0..31)>
            <u32: Offset of string table>
            <u32: Offset of gamemode string table offsets>
            <u64: Creation time (the time at which the map finished compiling in UTC Unix seconds)>
            <u16: String table offset of name>
            <u16: String table offset of description>
            <u16: String table offset of authors>
            <u16: String table offset of compiler info>
            <char[]: String table>
            [u16: String table offset of gamemode]...

        Level table:
            <u32: Level count (must be at least 1)>
            <u32: Offset of <Level>>...
            <Level>...
        Level:
            <u32: Offset of <String table>>
            <u32: Offset of shared <Entity table>>
            <u32: Offset of <Client level data>>
            <u32: Offset of <Server level data>>
            <u32: Offset of <Chunk table>>
            <u16: Material count>
            <u16: <Physics material> count>
            <u16: <Sound material> count>
            <u16: <Path material> count>
            <u32: Offset of first <Material>>
            <u32: Offset of first <Physics material>>
            <u32: Offset of first <Sound material>>
            <u32: Offset of first <Path material>>
            <<Chunk index>: Initial chunk>
            <u16: Air physics material>
            <float[3]: XYZ gravity>
            <String table>
            [Material]...
            [Physics material]...
            [Sound material]...
            [Path material]...
            <<Entity table (see 'map entities.txt')>: Shared entities>
            <Client level data>
            <Server level data>
            <Chunk table>
        Client level data:
            <u32: Offset of <String table>>
            <u16: <Basic animated material data> count>
            <u16: <Advanced animated material data> count>
            <u16: <Material wave info> count>
            <u8: <Skybox> count>
            <u32: Offset of first <Client-side material>>
            <u32: Offset of <Basic animated material data> offsets>
            <u32: Offset of <Advanced animated material data> offsets>
            <u32: Offset of first <Material wave info>>
            <u32: Offset of first <Skybox>>
            <Sound environment>
            <String table>
            [u32: Offset of <Basic animated material data>]...
            [u32: Offset of <Advanced animated material data>]...
            [Client-side material]...
            [Basic animated material data]...
            [Advanced animated material data]...
            [Material wave]...
            [Skybox]...
            [<Chunk table>: Skybox chunk table]...
        Server level data:
            <<Entity table (see 'map entities.txt')>: Server entities>

        Chunk table:
            <Chunk count>
            <u8: Chunk size (2^n)>
            <<World coordinate>: Center>
            <u32: Offset of <Chunk> (ordered by [Y][X][Z])>...
            <Chunk>...
        Chunk:
            <u32: Offset of <String table>>
            <u32: Offset of shared <Entity table>>
            <u32: Offset of <Client chunk data>>
            <u32: Offset of <Server chunk data> (0 if none)>
            <u32: Region count>
            <u32: Active chunk index count>
            <u16: Branch node count>
            <u16: Vis info node count>
            <u16: Lighting info node count>
            <u16: Geometry node count>
            <u16: Extended geometry node count>
            <u16: Collider node count>
            <u16: Extended collider node count>
            <u16: Material node count>
            <u16: Extended material node count>
            <u16: Physics material node count>
            <u16: Extended physics material node count>
            <u16: Sound material node count>
            <u16: Pathing node count>
            <u16: Vis map chunk reference count>
            <u16: Vis map node reference count>
            <u8: Dynamic light count>
            <u8: Fast light count>
            <u8: Material map length>
            <u8: Physics material map length>
            <u8: Sound material map length>
            <u8: Path material map length>
            <u32: Offset of first <Region>>
            <u32: Offset of first active chunk index>
            <u32: Offset of material map (0 for none)>
            <u32: Offset of physics material map (0 for none)>
            <u32: Offset of sound material map (0 for none)>
            <u32: Offset of path material map (0 for none)>
            <u32: Offset of first <Dynamic light>>
            <u32: Offset of first <Fast light>>
            <u32: Offset of compressed <Compressed chunk data>>
            <<Node type>: Root node type>
            <String table>
            [Region]...
            [<Chunk index>: Active chunk index]...
            [u16[]: Material map]
            [u16[]: Physics material map]
            [u16[]: Sound material map]
            [u16[]: Path material map]
            [Dynamic light]...
            [Fast light]...
            <<Entity table (see 'map entities.txt')>: Shared entities>
            <u8[]: Compressed <Compressed chunk data>>
            <Client chunk data>
            [Server chunk data]
        Compressed chunk data:
            [Branch node]...
            [Vis info node]...
            [Collider node]...
            [Extended collider node]...
            [Material node]...
            [Extended material node]...
            [Physics material node]...
            [Extended physics material node]...
            [Sound material node]...
            [Pathing node]...
            [Vis map chunk reference]...
            [<Node reference>: Vis map node reference]...
        Client chunk data:
            <u16: Index count>
            <u16: Vertex count>
            <u8: <Lightmap> count>
            <u16: Dynamic light node reference count>
            <u16: <Dynamic light lightmap> count>
            <u16: Fast light node reference count>
            <u32: Fast light vertex range count>
            <u32: Fast light multiplier count>
            <u32: Offset of compressed <Client compressed chunk data>>
            <u32: Offset of first <Lightmap>>
            <u32: Offset of first <Client-side dynamic light>>
            <u32: Offset of <Dynamic light lightmap> offsets>
            <u32: Offset of first <Client-side fast light>>
            <u8[]: Compressed <Client compressed chunk data>>
            [Lightmap]...
            [Client-side dynamic light]...
            [Client-side fast light]...
            [u32: Offset of <Dynamic light lightmap>]...
            [Client-side dynamic light lightmap]...
        Client compressed chunk data:
            [Lighting info node]...
            [Geometry node]...
            [Extended geometry node]...
            [Client-side geometry node]...
            [Client-side extended geometry node]...
            <u16[][3]: Mesh indices>
            <float[][3]: Mesh vertices>
            <float[][2]: Mesh UVs>
            <float[][2]: Mesh lightmap UVs>
            <float[][3]: Mesh normals>
            [Dynamic light node reference]...
            [Fast light node reference]...
            [Fast light vertex range]...
            [u8: Fast light multiplier]...
        Server chunk data:
            <<Entity table (see 'map entities.txt')>: Server entities>

        Chunk count:
            <u32:
                <8 bits: Chunk Y count minus 1>
                <12 bits: Chunk X count minus 1>
                <12 bits: Chunk Z count minus 1>
            >
        Chunk index:
            <u32:
                <8 bits: Chunk Y>
                <12 bits: Chunk X>
                <12 bits: Chunk Z>
            >

        World coordinate:
            <<Chunk index>: Chunk>
            <float[3]: In-chunk XYZ position>

        Region:
            <float[3]: (+X, +Y, +Z) corner>
            <float[3]: (-X, -Y, -Z) corner>
            <<Chunk count>: Load radius>
            <u32: Index of first active chunk index>
            <u32: Index count>

        Node type:
            <u8:
                { PMF_NODE_BRANCH
                | PMF_NODE_VIS
                | PMF_NODE_LIGHT
                | PMF_NODE_GEOM
                | PMF_NODE_EXGEOM
                | PMF_NODE_COLL
                | PMF_NODE_EXCOLL
                | PMF_NODE_MAT
                | PMF_NODE_EXMAT
                | PMF_NODE_PHYSMAT
                | PMF_NODE_EXPHYSMAT
                | PMF_NODE_SNDMAT
                | PMF_NODE_PATH
                | PMF_NODE_NONE }
            >
        Node reference:
            <Node type>
            <u16: Index>

        Branch node:
            <<Node type>[8]: Child types ([Y < 0][Z < 0][X < 0])>
            <u16[8]: Child indices ([Y < 0][Z < 0][X < 0])>

        Visibility info node:
            <Node reference>
            <u32: Vis map index>
        Lighting info node:
            <Node reference>
            <u8:
                <7 bits: 0>
                <1 bit: Additive>
            >
            <u8: Lightmap>
            <u8[3]: RGB base light>

        Geometry node:
            <<Node reference>: Next LOD (type must be NONE, GEOM, or GEOMEX)>
            <u8: LOD count of current node>
            <u16:
                <3 bits: 0>
                <1 bit: Not solid>
                <2 bits: -Z triangle count> <2 bits: -Y triangle count> <2 bits: -X triangle count>
                <2 bits: +Z triangle count> <2 bits: +Y triangle count> <2 bits: +X triangle count>
            >
            <u16: Index of first triangle>
        Extended geometry node:
            <<Node reference>: Next LOD (type must be GEOM or GEOMEX)>
            <u8: LOD count of current node>
            <u8[6]: Triangle counts (+X, +Y, +Z, -X, -Y, -Z)>
            <u16: Index of first triangle>

        Collider node:
            <Node reference>
        Extended collider node:
            <Node reference>
            <float[8][3]: Corner XYZ coords ([Y < 0][Z < 0][X < 0])>

        Material node:
            <Node reference>
            <u8: Material>
        Extended material node:
            <Node reference>
            <u8[6]: Materials (+X, +Y, +Z, -X, -Y, -Z)>

        Physics material node:
            <Node reference>
            <u8: Physics material>
        Extended physics material node:
            <Node reference>
            <u8[6]: Physics materials (+X, +Y, +Z, -X, -Y, -Z)>

        Sound material node:
            <Node reference>
            <u8: Sound material>

        Pathing node:
            <Node reference>
            <u8: Path material>

        Vis map chunk reference:
            <Chunk index>
            <u16: Index of first node reference>
            <u16: Node reference count>

        Material:
            <<String>: Name>
            <u32: User-defined data>
        Client-side material:
            <u8:
                <1 bit: Sort>
                <1 bit: Draw backfaces>
                <2 bits:
                    { PMF_MATDETAIL_MUL
                    | PMF_MATDETAIL_ADD
                    | PMF_MATDETAIL_BUMP
                    | PMF_MATDETAIL_NORMAL }
                >
                <2 bits:
                    { PMF_MATRENDMODE_MUL
                    | PMF_MATRENDMODE_ADD }
                >
                <2 bits:
                    { PMF_MATTYPE_NORMAL
                    | PMF_MATTYPE_BASANIM
                    | PMF_MATTYPE_ADVANIM }
                >
            >
            <u8[4]: RGBA color>
            <u8[4]: RGBA detail tint>
            <u8[4]: RGBA matcap tint>
            <u8[3]: RGB emission>
            <u8: Shading>
            <<String>: Texture (none if empty)>
            <<String>: Detail texture (none if empty)>
            <<String>: Matcap texture (none if empty)>
            <float[2]: UV offset (applied after scale)>
            <float[2]: UV scale>
            <float[2]: Detail texture UV offset (applied after scale)>
            <float[2]: Detail texture UV scale>
            <u16:
                { Ignored
                | Index of basic animated material data
                | Index of advanced animated material data }
            >
            <u16: Wave info index (0xFFFF for none)>
            <u8: Skybox (0xFF for none)>
        Basic animated material data:
            <u8: Extra texture count>
            <u32: Texture advance time in microseconds>
            <float[2]: Texture UV scroll per second>
            [<String>: Extra texture]...
        Advanced animated material data:
            <u32: Microseconds per frame>
            <u8: Color keyframe count>
            <u8: Detail tint keyframe count>
            <u8: Matcap tint keyframe count>
            <u8: Emission keyframe count>
            <u8: Shading keyframe count>
            <u8: Texture keyframe count>
            <u8: Detail texture keyframe count>
            <u8: Matcap texture keyframe count>
            <u8: UV offset keyframe count>
            <u8: UV scale keyframe count>
            <u16: Color animation duration>
            <u16: Detail tint animation duration>
            <u16: Matcap tint animation duration>
            <u16: Emission animation duration>
            <u16: Shading animation duration>
            <u16: Texture animation duration>
            <u16: Detail texture animation duration>
            <u16: Matcap texture animation duration>
            <u16: UV offset animation duration>
            <u16: UV scale animation duration>
            <u8[]: Compressed <Animated material keyframe data>>
        Animated material keyframe data:
            [u8: Color frame skip]...
            [u8: Detail tint frame skip]...
            [u8: Matcap tint frame skip]...
            [u8: Emission frame skip]...
            [u8: Shading frame skip]...
            [u8: Texture frame skip]...
            [u8: Detail texture frame skip]...
            [u8: Matcap texture frame skip]...
            [u8: UV offset frame skip]...
            [u8: UV scale frame skip]...
            [<Animated material color interp mode>: Color interp]...
            [<Animated material color interp mode>: Detail tint interp]...
            [<Animated material color interp mode>: Matcap tint interp]...
            [<Animated material color interp mode>: Emission interp]...
            [<Animated material interp mode>: Shading interp]...
            [<Animated material interp mode>: Texture interp]...
            [<Animated material interp mode>: Detail texture interp]...
            [<Animated material interp mode>: Matcap texture interp]...
            [<Animated material interp mode>: UV offset interp]...
            [<Animated material interp mode>: UV scale interp]...
            [u8[4]: Color data]...
            [u8[4]: Detail tint data]...
            [u8[4]: Matcap tint data]...
            [u8[3]: Emission data]...
            [u8: Shading data]...
            [<String>: Texture data]...
            [<String>: Detail texture data]...
            [<String>: Matcap texture data]...
            [float[2]: UV offset index data]...
            [float[2]: UV scale index data]...
        Animated material interp mode:
            <u8:
                { PMF_MATINTERP_NONE
                | PMF_MATINTERP_LINEAR }
            >
        Animated material color interp mode:
            <u8:
                { PMF_MATCOLORINTERP_NONE
                | PMF_MATCOLORINTERP_LINEAR_RGB
                | PMF_MATCOLORINTERP_LINEAR_HSV_CW
                | PMF_MATCOLORINTERP_LINEAR_HSV_CCW
                | PMF_MATCOLORINTERP_LINEAR_OKLCH }
            >
        Material wave info:
            <float[2]: Velocity>
            <float: Height>
            <float: Scale>
            <<String>: Global bone>
            <float: Bone influence>

        Physics material:
            <<String>: Name>
            <u32: User-defined data>
            <u8:
                <7 bits: 0>
                <1 bit: Not solid>
            >
            { <float: Static friction>
              <float: Kinetic friction>
              <float: Bounce>
            | <float: Density>
              <float: Terminal velocity>
              <float: 0> }

        Sound material:
            <<String>: Name>
            <u32: User-defined data>
            <float: Range dampening>
            <float: Volume dampening>
            <float: Frequency dampening>

        Sound environment:
            <float: Low pass filter>
            <float: High pass filter>
            <float: Reverb delay>
            <float: Reverb feedback>
            <float: Reverb mix>
            <float: Reverb low pass filter>
            <float: Reverb high pass filter>

        Skybox:
            <<String>: Name>
            <u16: +X skybox material>
            <u16: +Y skybox material>
            <u16: +Z skybox material>
            <u16: -X skybox material>
            <u16: -Y skybox material>
            <u16: -Z skybox material>
            <u16: Top cloud layer material (0xFFFF for none)>
            <u16: Bottom cloud layer material (0xFFFF for none)>
            <u32: Offset of 3D skybox <Chunk table> (0 for none)>

        Lightmap:
            <u8: <4 bits: Height (2^n)> <4 bits: Width (2^n)>>
            <u8[]: Compressed <u8[][3]: RGB luxel>>

        Dynamic light:
            <<String>: Name (none if empty)>
            <u8:
                <6 bits: 0>
                <1 bit: Preserve>
                <1 bit: Enabled>
            >
        Client-side dynamic light:
            <u16: Index of first dynamic light lightmap>
            <u8: Lightmap count>
        Dynamic light lightmap:
            <u8: Base lightmap>
            <u8[]: Compressed <u8[][3]: RGB luxel>>
        Dynamic light node reference:
            <u16: Lighting info node index>
            <u8[3]: RGB color>

        Fast light:
            <<String>: Name (none if empty)>
            <u8:
                <6 bits: 0>
                <1 bit: Preserve>
                <1 bit: Enabled>
            >
            <u8: Initial intensity>
        Client-side fast light:
            <u8[3]: RGB color>
            <u32: Index of first vertex range>
            <u16: Vertex range count>
            <u32: Index of first multiplier>
        Fast light node reference:
            <u16: Lighting info node index>
            <u8: Multiplier>
        Fast light vertex range:
            <u16: Index of first vertex>
            <u16: Vertex count>
            <u16: Index offset of first multiplier>

        String table:
            <u32: Uncompressed size (0 if not compressed)>
            [u32: Size (present if not compressed)]
            <{u8|char}[]: Data>
        String:
            <u32: Offset in string table of null-terminated string>

        User-defined attribute:
            <<String>: Name>
            <User-defined attribute data (see 'user-defined attrib data.txt')>

        Extension table:
            <u32: Extension count> [u32: Offset of <Extension>]...
            [Extension]...
        Extension:
            (See 'map extensions.txt')
            <u8:
                <7 bits: 0>
                <1 bit: Support required>
            >
            <char[15]: Name>
            <u32: Data size>
            <u8[]: Data>
