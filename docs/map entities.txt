Entity table:
    <u32: Entity count>
    <u8: Component group count>
    <u32: Offset of first <Component group info>>
    <u32: Offset of compressed <Entities>>
    [Component group info]...
    <u8[]: Compressed <Entities>>

Entities:
    [Entity]...
    [Component]...
Component group info:
    <u32:
        <8 bits: <Component type> (NONE to terminate; if not NONE, must be higher than the previous)>
        <24 bits: Count>
    >
    <u32: Size of uncompressed data in group>
Entity:
    <u32: Gamemodes bitmask>
    <u32: Size of following data>
    <<Component index>: First component>
    <u8:
        <7 bits: 0>
        <1 bit: Disabled>
    >
    <<Entity string>: Name>
    <u32: Teams bitmask>
Component:
    <u32: Gamemodes bitmask>
    <u32: Size of following data>
    <<Component index>: Next component>
    <u8:
        <7 bits: 0>
        <1 bit: Disabled>
    >
    <<Entity string>: Name>

Coordinate component data:
    <<World coordinate>: Position>

Transform component data:
    <<Component index>: Parent transform or coordinate, or NONE>
    <u8:
        <5 bits: 0>
        <1 bit: Reset scale>
        <1 bit: Reset rotation>
        <1 bit: Is matrix>
    >
    { <<World coordinate>: Offset>
      <float[3]: XYZ YXZ rotation>
      <float[3]: XYZ scale>
    | <Chunk index>
      <float[3][3]: Matrix> }

Follower component data:
    <<Component index>: Coordinate or transform to act on>
    <<Entity string>: Entity name>
    <<Entity string>: Component name of coordinate, transform, or model>
    <<Entity string>: Bone>

Physics info component data:
    <<Component index>: Coordinate or transform to act on>
    <<Component index>: First collider or NONE>
    <u8:
        <5 bits: 0>
        <1 bit: Face gravity>
        <1 bit: Can move others>
        <1 bit: Can be moved>
    >
    <float: Mass>
    <float[3]: XYZ velocity>
    <float[3]: XYZ acceleration>

Collider component data:
    <<Component index>: First shape or coordinate>
    <<Component trigger output>: On collision>
    <u16: Physics material (-1 for none)>

Mover component data:
    <<Component index>: Coordinate, transform, or physics info to act on>
    <<Component index>: Destination coordinate or NONE>
    <u8:
        <6 bits: 0>
        <1 bit: If physics, modify acceleration instead of position>
        <1 bit: If physics, modify velocity instead of position>
        <1 bit: Add per second (0) or set (1)>
    >
    <float[3]: XYZ amount>

    <<Component index>: Coordinate (NONE for 2D emitter)>

        <3 bits: Output channel count minus 1>

        <3 bits: Channel 4 output channel index>
        <3 bits: Channel 3 output channel index>
